## 安装部署

### 方法一：下载预编译版本（推荐）

1. 前往 [Releases 页面](https://github.com/YOUR_USERNAME/todoandsearch/releases)
2. 下载最新版本的 `TodoSearch-*-portable.exe`（便携版）或 `TodoSearch-*-Setup.exe`（安装版）
3. 便携版直接双击运行；安装版运行安装程序后从开始菜单启动

### 方法二：从源码本地构建

#### 前置条件

- **Node.js** >= 20.x（[下载](https://nodejs.org/)）
- **npm**（随 Node.js 一同安装）
- **Git**（[下载](https://git-scm.com/downloads)）

#### 步骤

```powershell
# 1. 克隆仓库
git clone https://github.com/YOUR_USERNAME/todoandsearch.git
cd todoandsearch

# 2. 安装所有依赖
npm install

# 3. 生成应用图标
node scripts/generate-icon.js

# 4. 启动开发模式（调试运行）
npm start
```

#### 打包为 exe

```powershell
# 构建 Windows 安装包（会在 release/ 目录生成 exe）
npm run dist:win
```

构建产物说明：

| 文件 | 说明 |
|------|------|
| `TodoSearch-1.0.0-64.exe` | NSIS 安装包 |
| `TodoSearch-1.0.0-64-portable.exe` | 免安装便携版 |

## 待办清单

### 添加待办

1. **选择分类颜色**：在输入框上方点击色块（8种颜色可选）
2. **输入内容**：在输入框中填写待办事项（最多200字）
3. **确认添加**：按 `Enter` 键或点击「添加」按钮

### 管理待办

| 操作 | 方式 |
|------|------|
| ✅ 标记完成/未完成 | 点击待办左侧的圆圈，或直接点击文字 |
| ⭐ 置顶/取消置顶 | 点击待办右侧的五角星图标 |
| 🗑️ 删除 | 点击待办右侧的垃圾桶图标 |
| 🔍 筛选视图 | 点击顶部「全部/进行中/已完成」按钮 |

### 颜色分类

| 颜色 | 标签 | 适用场景 |
|------|------|----------|
| 灰色 `#8e8e93` | 默认 | 普通事项 |
| 绿色 `#34c759` | 工作 | 工作任务 |
| 蓝色 `#007aff` | 学习 | 学习计划 |
| 紫色 `#af52de` | 个人 | 个人事务 |
| 黄色 `#ffcc00` | 提醒 | 提醒事项 |
| 橙色 `#ff9500` | 重要 | 重要事项 |
| 红色 `#ff3b30` | 紧急 | 紧急事务 |
| 粉色 `#ff2d55` | 生活 | 生活琐事 |

### 数据存储

所有待办数据保存在浏览器的 `localStorage` 中，关闭窗口或重启应用后数据不丢失。

> ⚠️ 清除浏览器缓存或卸载应用会导致数据丢失。建议定期备份 `localStorage` 数据。

## 月视图

按月浏览待办的新增与完成情况。

### 日历导航

- **◀ / ▶ 按钮**：切换到上/下一个月
- **「今天」按钮**：快速跳转到当前月份
- **日期格**：显示日期数字，以及当天新增（绿色）和完成（蓝色）的待办数量

### 查看日详情

1. 点击任意日期格，进入当日详情视图
2. 详情视图分为「新增」和「完成」两个列表
3. 每条待办显示其对应的颜色标签
4. 已完成的待办显示删除线
5. 点击「← 返回」回到月历

### 数据联动

在「待办」tab 中进行添加、完成、删除操作后，月视图会自动刷新。

## 文件搜索

全盘按文件名搜索文件，支持实时流式返回结果。

### 基本搜索

1. 切换到「搜索」标签
2. 在输入框中输入文件名关键词（支持中英文）
3. 输入后自动搜索（300ms 防抖），或按 `Enter` 立即搜索
4. 结果实时显示，每找到一个文件就追加到列表中
5. 按 `Escape` 清空搜索

### 搜索范围

- 自动扫描所有本地磁盘（C:\, D:\ 等）
- 优先搜索用户目录（家目录优先）
- 跳过系统目录（Windows, Program Files, AppData, temp 等）
- 最大递归深度：15 层
- 最大返回结果：3000 条

### 结果操作

| 操作 | 方式 |
|------|------|
| 📂 打开文件 | 左键单击搜索结果 |
| 📁 打开所在文件夹 | 右键 →「打开所在文件夹」 |
| 📋 复制文件路径 | 右键 →「复制路径」 |
| 📄 复制文件本身 | 右键 →「复制文件」（可在资源管理器粘贴） |
| 📊 查看文件信息 | 结果显示文件名、路径、大小、修改时间 |

### 搜索技巧

- **精确搜索**：输入完整的文件名或部分关键词
- **中文搜索**：支持中文文件名搜索
- **减少结果**：关键词越长越精确，避免单个字母/单字

## 窗口操作

### 悬浮窗特性

- **窗口置顶**：始终显示在其他窗口之上
- **可拖拽**：按住顶部标题栏任意位置拖拽移动
- **可调整大小**：从窗口边缘拖拽调整尺寸

### 标题栏按钮

| 按钮 | 功能 |
|------|------|
| `—`（最小化） | 最小化到任务栏 |
| `✕`（关闭） | 隐藏到系统托盘（不退出应用） |
| 托盘图标 | 右键托盘图标可「显示/隐藏」或「退出」 |

### 系统托盘

- 关闭窗口时应用隐藏到系统托盘，继续在后台运行
- 右键托盘图标弹出菜单：
  - **显示/隐藏**：切换窗口可见性
  - **退出**：完全退出应用
- 点击托盘图标可快速切换窗口显示状态

## 故障排查

### 应用无法启动

1. 确认系统为 Windows 10 或更高版本
2. 尝试以管理员身份运行
3. 检查杀毒软件是否拦截（添加信任）

### 文件搜索无结果

1. 确认关键词拼写正确
2. 尝试搜索更宽泛的关键词
3. 检查是否选择了正确的磁盘分区
4. 系统目录被默认跳过（Windows, Program Files 等）

### 待办数据丢失

1. 检查浏览器 localStorage 是否被清除
2. 应用更新不影响本地数据
3. 如使用便携版，数据保存在用户目录的 `AppData\Local\` 中

## 常见问题

**Q: 支持多语言吗？**
A: 当前仅支持中文界面。

**Q: 能搜索网络驱动器吗？**
A: 仅搜索本地磁盘，不支持网络映射驱动器。

**Q: 搜索速度如何？**
A: 采用异步并发遍历，普通关键词在全盘搜索中约 5-30 秒完成，结果实时流式显示。

**Q: 如何在任务栏固定应用？**
A: 打开应用后，在任务栏图标上右键 →「固定到任务栏」。最小化后仍可从任务栏恢复。

**Q: 如何开机自启？**
A: 创建一个快捷方式，放入 `shell:startup` 文件夹：
```
C:\Users\用户名\AppData\Roaming\Microsoft\Windows\Start Menu\Programs\Startup
```
